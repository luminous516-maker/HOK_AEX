# Aetherix E-sports 길드 가입 신청 홈페이지

아너오브킹즈길드 에트릭스 이스포츠 공식 길드 가입 신청 플랫폼

## 프로젝트 개요

Aetherix E-sports에 가입하고 싶은 Honor of Kings 유저들이 간편하게 지원서를 작성하고, 운영진은 이를 효율적으로 관리할 수 있는 길드 가입 신청 홈페이지입니다.

## 핵심 기능

- 🎮 길드 소개 페이지
- 📝 길드 가입 신청서 작성
- 🏆 티어 및 챔피언스리그 점수 선택
- 👥 운영진 지원자 관리
- ✅ 신청서 승인/거절 처리

## 기술 스택

- HTML5
